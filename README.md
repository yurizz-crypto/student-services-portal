# University Student Services Portal

## Project Description
A TypeScript-based environment setup for the student portal.

## Requirements
- Node.js
- npm

## Installation Instructions
1. Clone the repository
2. Run `npm install`

## How to Run the Project
Run `npx ts-node src/index.ts`

## How to Run Linting and Formatting
- Lint: `npm run lint`
- Format: `npm run format`

## Development Workflow
Features are developed on separate branches and merged via Pull Requests.

## AI Usage Policy
AI tools may be used to assist development. All AI-generated code must be reviewed, modified when necessary, tested, and verified before commit.
